## 核心数据流

### 1. 实时检测流程
```
网络流量 → 捕获 → Redis队列 → 特征提取 → 模型推理 → 告警生成 → 前端展示
```

### 2. 模型训练流程
```
数据集 → 预处理 → 特征工程 → 模型训练 → 评估 → 保存模型 → 激活使用
```

### 3. 实验管理流程
```
配置实验 → 加载数据 → 训练多模型 → 融合预测 → 保存结果 → 对比分析
```

## 模块说明

| 模块 | 功能 | 技术 |
|------|------|------|
| Traffic Capture | 网络流量捕获 | Scapy/PCAP |
| Feature Extractor | 特征提取 | NumPy/Pandas |
| Inference Engine | 模型推理 | LightGBM/XGBoost/TensorFlow |
| Alert Engine | 告警生成 | SQLAlchemy |
| SHAP Analyzer | 可解释性 | SHAP |
| WebSocket Manager | 实时推送 | FastAPI WebSocket |
