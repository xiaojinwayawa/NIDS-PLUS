│             网络环境（多主机）               │
├─────────────────────────────────────────────┤

└─────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────┐
│             网卡（混杂模式）                 │
├─────────────────────────────────────────────┤
│        packet → packet → packet → ...       │
└─────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────┐
│            Scapy 原始套接字                  │
├─────────────────────────────────────────────┤
│  sniff()  rdpcap()  wrpcap()  send()        │
│              Packet对象                      │
│      Ether/IP/TCP/UDP/Raw 层次结构          │
└─────────────────────────────────────────────┘
                        │
            ┌─────────────┴─────────────┐
            │                           │
            ▼                           ▼
┌─────────────────────┐     ┌─────────────────────┐

├─────────────────────┤     ├─────────────────────┤
│ rdpcap()读取文件    │     │ sniff()监听接口     │

            │                           │

                        │

│              流聚合模块                      │
├─────────────────────────────────────────────┤
│ 五元组标识: src_ip+dst_ip+src_port+dst_port+protocol │
│ 状态机: ACTIVE → IDLE → FINISHED/TIMEOUT    │
│ 超时: TCP/UDP/ICMP=120s, 空闲=5s           │
└─────────────────────────────────────────────┘

数据流向说明：
1. 网络环境中的主机通信产生数据包
2. 网卡在混杂模式下捕获所有数据包
3. Scapy通过原始套接字处理数据包
4. 两种工作模式：PCAP文件回放和实时捕获
5. 处理后的数据包推送到Redis消息队列
6. 流聚合模块基于五元组进行会话级聚合
7. 最终输出流级特征供模型推理使用
