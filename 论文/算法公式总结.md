# LightGBM与1D-CNN算法及公式总结

## 一、LightGBM算法原理

### 1.1 算法概述

LightGBM（Light Gradient Boosting Machine，轻量级梯度提升决策树）是一种基于梯度提升决策树（GBDT）的高效机器学习算法[1]。与传统的GBDT算法不同，LightGBM采用基于梯度的单边采样（GOSS）和互斥特征捆绑（EFB）两项核心技术，大幅提升了训练速度和内存效率。

### 1.2 梯度提升原理

LightGBM属于梯度提升框架，其核心思想是通过不断添加决策树来拟合前一轮的残差。给定训练数据集$D = \{(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)\}$，模型的目标是学习一个加法模型：

$$F_M(x) = \sum_{m=1}^{M} \gamma_m h_m(x)$$

其中$h_m(x)$是第$m$棵决策树，$\gamma_m$是叶子节点的权重值。

在第$m$轮迭代中，模型学习一棵决策树$h_m(x)$来拟合前一轮的负梯度（残差）：

$$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$

其中$L(y_i, F(x_i))$是损失函数，对于二分类问题使用对数损失：

$$L(y, F) = -[y \cdot \log(\sigma(F)) + (1-y) \cdot \log(1-\sigma(F))]$$

其中$\sigma(F) = \frac{1}{1 + e^{-F}}$是sigmoid函数。

### 1.3 LightGBM叶子节点分裂准则

LightGBM使用基于直方图的决策树学习算法。对于每个叶子节点，分裂候选点基于特征的连续值构造的直方图确定。分裂增益计算公式为：

$$\text{Gain} = \frac{1}{2} \left[ \frac{(\sum_{i \in I_L} g_i)^2}{\sum_{i \in I_L} h_i + \lambda} + \frac{(\sum_{i \in I_R} g_i)^2}{\sum_{i \in I_R} h_i + \lambda} - \frac{(\sum_{i \in I} g_i)^2}{\sum_{i \in I} h_i + \lambda} \right] - \gamma$$

其中：
- $I_L$和$I_R$分别是分裂后左右子节点的数据集合
- $g_i = \partial_{F_{m-1}} L(y_i, F_{m-1}(x_i))$是一阶导数（梯度）
- $h_i = \partial^2_{F_{m-1}} L(y_i, F_{m-1}(x_i))$是二阶导数（Hessian）
- $\lambda$是L2正则化系数
- $\gamma$是叶子节点数正则化系数

### 1.5 LightGBM预测公式

对于二分类任务，LightGBM的预测概率为：

$$P(y=1|x) = \sigma\left(\sum_{m=1}^{M} \gamma_m h_m(x)\right) = \frac{1}{1 + e^{-\sum_{m=1}^{M} \gamma_m h_m(x)}}$$

对于多分类任务，LightGBM使用softmax函数计算每个类别的概率：

$$P(y=k|x) = \frac{e^{F_k(x)}}{\sum_{j=1}^{K} e^{F_j(x)}}$$

其中$F_k(x) = \sum_{m=1}^{M} \gamma_m h_m(x)$是第$k$个类别的得分，$K$是类别总数。

### 1.6 LightGBM多分类损失函数

多分类任务使用交叉熵损失函数：

$$L(y, \hat{y}) = -\sum_{k=1}^{K} y_k \log(\hat{y}_k)$$

其中$y_k$是真实标签的one-hot编码，$\hat{y}_k$是模型预测的第$k$个类别的概率。

## 二、1D-CNN算法原理

### 2.1 算法概述

1D-CNN（一维卷积神经网络）是一种擅长处理序列数据的深度学习模型[2]。与处理图像的2D-CNN不同，1D-CNN在网络流量特征向量上使用一维卷积操作，能够自动提取特征的局部模式，非常适合网络流量分析任务。

### 2.2 一维卷积操作

一维卷积操作可以表示为：

$$y_i = \sum_{j=1}^{k} x_{i+j-1} \cdot w_j + b$$

其中：
- $x$是输入特征向量
- $w$是卷积核权重
- $b$是偏置项
- $k$是卷积核大小
- $y_i$是输出特征图的第$i$个元素

在网络中，系统采用Same卷积（填充0使输出与输入长度一致）和ReLU激活函数：

$$\text{ReLU}(y_i) = \max(0, y_i)$$

### 2.4 批归一化层

批归一化（Batch Normalization）层对每一批数据进行标准化：

$$\hat{x}^{(k)} = \frac{x^{(k)} - \mu_B^{(k)}}{\sqrt{\sigma_B^{(k)2} + \epsilon}}$$

$$y^{(k)} = \gamma^{(k)} \hat{x}^{(k)} + \beta^{(k)}$$

其中$\mu_B$和$\sigma_B$是批均值和批方差，$\gamma$和$\beta$是可学习的缩放和平移参数。

### 2.5 1D-CNN损失函数

二分类任务使用二分类交叉熵损失函数：

$$L(y, \hat{y}) = -\frac{1}{N} \sum_{i=1}^{N} [y_i \cdot \log(\hat{y}_i) + (1-y_i) \cdot \log(1-\hat{y}_i)]$$

多分类任务使用稀疏分类交叉熵损失函数：

$$L(y, \hat{y}) = -\frac{1}{N} \sum_{i=1}^{N} \sum_{k=1}^{K} \mathbb{1}_{\{y_i=k\}} \log(\hat{y}_{i,k})$$

其中$y_i$是真实标签，$\hat{y}_i$是模型预测的概率值，$K$是类别总数。

### 2.6 1D-CNN预测公式

二分类任务经过sigmoid激活函数输出：

$$P(y=1|x) = \sigma(z) = \frac{1}{1 + e^{-z}}$$

多分类任务经过softmax激活函数输出：

$$P(y=k|x) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

其中$z$是输出层之前线性变换的结果，$K$是类别总数。

## 三、模型融合策略

### 3.1 二分类加权融合原理

本系统采用加权融合策略综合LightGBM和1D-CNN两个模型的预测结果。加权融合的核心思想是给不同模型分配不同的权重，体现各模型在最终决策中的贡献度[3]。

### 3.2 二分类加权融合公式

给定$n$个模型的二分类概率输出$P_1, P_2, ..., P_n$，加权融合后的概率为：

$$P_{\text{fusion}} = \frac{\sum_{i=1}^{n} w_i \cdot P_i}{\sum_{i=1}^{n} w_i}$$

其中$w_i$是第$i$个模型的权重，满足$w_i > 0$。

最终预测结果为：

$$\hat{y} = \begin{cases} 1 & \text{if } P_{\text{fusion}} > 0.5 \\ 0 & \text{otherwise} \end{cases}$$

### 3.3 多分类加权融合公式

对于多分类任务，给定$n$个模型的概率矩阵$\mathbf{P}_1, \mathbf{P}_2, ..., \mathbf{P}_n$，其中$\mathbf{P}_i \in \mathbb{R}^{N \times K}$，加权融合后的概率矩阵为：

$$\mathbf{P}_{\text{fusion}} = \frac{\sum_{i=1}^{n} w_i \cdot \mathbf{P}_i}{\sum_{i=1}^{n} w_i}$$

最终预测类别为：

$$\hat{y} = \arg\max_{k} \mathbf{P}_{\text{fusion}}[:, k]$$

### 3.4 本系统融合配置

```python
# 模型权重配置
model_weights = {
    'lightgbm': 0.6,  # LightGBM权重0.6
    'cnn': 0.4        # 1D-CNN权重0.4
}

# 二分类融合推理过程
def _fusion_weighted_binary(self, binary_probs: Dict[str, np.ndarray], n_samples: int):
    weighted_probs = np.zeros(n_samples)
    total_weight = 0.0

    for key, probs in binary_probs.items():
        weight = self.model_weights.get(key, 1.0)
        weighted_probs += probs * weight
        total_weight += weight

    if total_weight > 0:
        weighted_probs /= total_weight

    predictions = (weighted_probs > 0.5).astype(int).tolist()
    confidences = weighted_probs.tolist()

    return predictions, confidences

# 多分类融合推理过程
def _fusion_weighted_multiclass(self, multiclass_probs: Dict[str, np.ndarray], n_samples: int, n_classes: int):
    weighted_probs = np.zeros((n_samples, n_classes))
    total_weight = 0.0

    for key, probs in multiclass_probs.items():
        weight = self.model_weights.get(key, 1.0)
        weighted_probs += probs * weight
        total_weight += weight

    if total_weight > 0:
        weighted_probs /= total_weight

    predictions = np.argmax(weighted_probs, axis=1).tolist()
    confidences = np.max(weighted_probs, axis=1).tolist()

    return predictions, confidences
```

## 四、评估指标

### 4.1 二分类评估指标

#### 4.1.1 准确率

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

#### 4.1.2 精确率

$$\text{Precision} = \frac{TP}{TP + FP}$$

#### 4.1.3 召回率

$$\text{Recall} = \frac{TP}{TP + FN}$$

#### 4.1.4 F1分数

$$\text{F1} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

其中：
- TP（True Positive）：真正例，实际为攻击且预测为攻击
- TN（True Negative）：真负例，实际为正常且预测为正常
- FP（False Positive）：假正例，实际为正常但预测为攻击
- FN（False Negative）：假负例，实际为攻击但预测为正常

### 4.2 多分类评估指标

#### 4.2.1 宏平均精确率（Macro-Precision）

$$\text{Macro-Precision} = \frac{1}{K} \sum_{k=1}^{K} \text{Precision}_k$$

其中$\text{Precision}_k$是第$k$个类别的精确率。

#### 4.2.2 宏平均召回率（Macro-Recall）

$$\text{Macro-Recall} = \frac{1}{K} \sum_{k=1}^{K} \text{Recall}_k$$

其中$\text{Recall}_k$是第$k$个类别的召回率。

#### 4.2.3 宏平均F1分数（Macro-F1）

$$\text{Macro-F1} = \frac{1}{K} \sum_{k=1}^{K} \text{F1}_k$$

其中$\text{F1}_k$是第$k$个类别的F1分数。

#### 4.2.4 加权平均F1分数（Weighted-F1）

$$\text{Weighted-F1} = \sum_{k=1}^{K} w_k \cdot \text{F1}_k$$

其中$w_k = \frac{n_k}{N}$是第$k$个类别的样本权重，$n_k$是第$k$个类别的样本数，$N$是总样本数。
